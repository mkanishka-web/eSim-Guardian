# eSim Guardian – Smart Environment Auditor

## About the Project
eSim Guardian is a Python-based Smart Environment Auditor that checks system information, dependencies, and tool compatibility. It calculates a system health score and generates a detailed report.

## Features
- Scan System Information
- Check Dependencies
- Check Tool Compatibility
- Calculate System Health Score
- Generate System Health Reports
- Error Logging

## Technologies Used
- Python
- psutil
- OS and Platform Modules

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/mkanishka-web/eSim-Guardian.git
   ```

2. Open the project folder:
   ```bash
   cd eSim-Guardian
   ```

3. Install dependencies:
   ```bash
   python -m pip install -r requirements.txt
   ```

4. Run the project:
   ```bash
   python -m src.main
   ```
